Privacy Policy

This application is an academic student project called "AI-Powered WhatsApp Chatbot for Student Information Management".

Information Used

The application processes WhatsApp messages sent by users to retrieve relevant student information from an authorized student database.

Purpose

The information is used only to demonstrate an academic student information management chatbot.

Data Sharing

The application does not sell user information or use it for advertising purposes.

Data Security

Access to student information is intended only for authorized users of the academic project.

Contact

For questions regarding this privacy policy, please contact the application administrator.
